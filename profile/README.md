# DigiScience Techsol

DigiScience helps teams assess one defined business or technology problem and choose a practical next step across workflow improvement, automation, AI, cloud or platform changes.

## Start with a bounded assessment

The [Solution Assessment](https://digisciencetechsol.com/solution-assessment) describes the problem and desired outcome, compares options, recommends a path and provides an implementation brief. Coding, a working proof of concept and production integration are scoped separately.
